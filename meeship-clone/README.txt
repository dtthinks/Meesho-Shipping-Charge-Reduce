MEESHIP FRONTEND CLONE (DEMO)

Open index.html in a modern browser, or serve this folder with a local static web server.

Included:
- Responsive landing page inspired by the supplied MeeShip page archive
- Image upload / drag-and-drop preview
- Local download of the selected image
- Sample showcase images extracted from the supplied archive

Important limitations:
- This is a reconstructed frontend demo, not the original source code.
- The supplied archive contained only the main compiled JavaScript bundle, not its referenced lazy-loaded chunks, so the original app could not be restored intact.
- The original server/API, AI processing, authentication, and real shipping calculations are not included.
- It does not promise or calculate actual Meesho shipping fees.

To run with Python installed, open a terminal in this folder and run:
  python -m http.server 8000
Then visit http://localhost:8000
